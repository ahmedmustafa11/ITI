# **Lab 3**



1. Write a program in **C** to read $n$ number of values in an array and display them in **reverse order**.

2. Write a program in **C** to **copy** the elements of one array into another array.

3. Write a program in **C** to count the total number of **duplicate elements** in an array.

4. Write a program in **C** to print all **unique elements** in an array.

5. Write a program in **C** to count the **frequency** of each element of an array.

6. Write a program in **C** to find the **maximum** and **minimum** elements in an array.

7. Write a program in **C** to sort elements of an array in **ascending order**.

8. Write a program in **C** to sort the elements of an array in **descending order**.

9. Write a program in **C** to convert a **decimal number** to a **binary number**.

10. Write a program in **C** to count the total number of **words** in a string.

11. Write a program in **C** to find the **length** of a string without using library functions.

12. Write a program in **C** to **compare** two strings without using string library functions.

13. Write a program in **C** to **copy** one string to another string.

14. Write a program in **C** to read a sentence and replace **lowercase** characters with **uppercase** and vice versa.
