# Lab 1

1. Write a C program to compute the **perimeter and area of a rectangle** with a height of 7 inches and a width of 5 inches.

2. Write a C program to **convert specified days into years, weeks, and days**.

3. Write a C program to **calculate the distance between two points** `(x1, y1)` and `(x2, y2)`.

4. Write a C program to **convert a given integer (in seconds) into hours, minutes, and seconds**.

5. Write a C program that **reads two integers and checks if they are multiplied or not**.

6. Write a C program that **reads an integer between 1 and 12 and prints the corresponding month of the year in English**.

7. Write a C program to **print all numbers between 1 and 100 that are divisible by a specified number**.
